# 常见问题

**Q：这是网易 UU 官方修复吗？** 不是，属于社区对客户端本地版本检查的兼容性实验。

**Q：Windows 7 32 位能用吗？** 目前工具仅针对 64 位 `GameViewer.exe`，尚未提供 x86 版本。

**Q：未知版本显示 `UNSUPPORTED` 怎么办？** 不要强行改偏移。提交脱敏 Issue，提供文件大小、SHA-256 和检测输出。

**Q：为什么已经打补丁，重启后又提示不支持？** 客户端可能自行更新并覆盖 EXE；重新运行 `Check_Win7.cmd`。不要在没有版本验证时反复强制写入。

**Q：为什么有安全软件提示签名异常？** 修改可执行文件会使原官方数字签名失效，属于预期风险。仍应自行核对本项目脚本，并从可信的官方渠道下载 UU 原版客户端。

**Q：进入云电脑排队代表完全兼容吗？** 不代表。仅验证了入口限制可解除；连接、付费、排队、GPU 解码及稳定性仍可能存在问题。

**Q：是否会修改 U 币、付费时间、远控认证或服务器？** 不会。本项目仅改本地系统版本检查指令。
