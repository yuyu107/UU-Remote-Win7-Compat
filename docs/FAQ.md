# 常见问题

**Q：这是网易 UU 官方修复吗？** 不是，属于社区对客户端本地版本检查的兼容性实验。

**Q：UU 远程不支持 Windows 7，难道不是因为使用了 Win7 不兼容的 API 吗？**

两者不能直接画等号。在已测试版本里，调试器确认了连接前主动执行的 Windows 版本拦截；放行后，普通远控画面、键鼠、声音、全屏和画质调整均已实测正常。因此，**至少这些功能不是因为 Win7 天然缺少必需 API 才无法运行**。但是安装目录的其他组件确实存在 Windows 8+ API 依赖，未测试的功能仍可能有真实的系统要求。具体证据见 [技术说明](TECHNICAL.md)。

**Q：Windows 7 32 位能用这个补丁吗？**

**不能。当前项目仅支持 Windows 7 SP1 64 位（x64）。** 我们在 Win7 SP1 32 位（x86）上实际测试：UU 远程安装时报“启动服务失败，错误码 216”；Windows 系统事件 7000 确认安装的 `GameViewerService.exe` 是 AMD64（64 位）程序，无法启动；桌面上的 `GameViewer.exe` 也提示 32/64 位架构不兼容。安装目录中的远控主程序、服务、串流核心等均为 x64，没有发现完整的 x86 远控构建。

这**不是**此前 Win7 x64 上的版本检测限制，而是实际程序架构不匹配。绕过错误码、修改版本判断或使用 API 兼容层，都无法让 32 位 Windows 直接运行 64 位 EXE。**不会提供 32 位补丁，也不再继续研究该方向。**

**Q：未知版本显示 `UNSUPPORTED` 怎么办？** 不要强行改偏移。提交脱敏 Issue，提供文件大小、SHA-256 和检测输出。

**Q：为什么已经打补丁，重启后又提示不支持？** 客户端可能自行更新并覆盖 EXE；重新运行 `Check_Win7.cmd`。不要在没有版本验证时反复强制写入。

**Q：为什么有安全软件提示签名异常？** 修改可执行文件会使原官方数字签名失效，属于预期风险。仍应自行核对本项目脚本，并从可信的官方渠道下载 UU 原版客户端。

**Q：进入云电脑排队代表完全兼容吗？** 不代表。仅验证了入口限制可解除；连接、付费、排队、GPU 解码及稳定性仍可能存在问题。

**Q：是否会修改 U 币、付费时间、远控认证或服务器？** 不会。本项目仅改本地系统版本检查指令。
